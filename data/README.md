# Coordinate data

`census_places_2025.zip` and `census_cousubs_2025.zip` contain 2025 U.S. Census Bureau Gazetteer files. The API uses their representative latitude/longitude points as approximate city or town locations when the supplied fuel-price CSV has no station coordinates.

Source: [U.S. Census Bureau 2025 Gazetteer files](https://www.census.gov/geographies/reference-files/time-series/geo/gazetteer-files.2025.html). The files are public U.S. government data. The original archives are kept so the source and derivation are reproducible.
